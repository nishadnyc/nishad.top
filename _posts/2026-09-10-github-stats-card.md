## Why Animated Stats Cards?

GitHub profiles are often the first impression developers make on recruiters, collaborators, and the open‑source community. A static list of repositories tells a story, but a dynamic, animated card:

- **Grabs attention** – Motion and color make the card stand out in a sea of plain text.
- **Shows real‑time data** – Visitors see up‑to‑date contributions, streaks, and repo stats.
- **Reflects personality** – Custom themes let you match your branding or mood.
- **Boosts credibility** – Highlighting stars, followers, and language mastery signals expertise.

## Under the Hood

- **Data Source** – The generator calls the official GitHub REST API to fetch up‑to‑date stats.  
- **Rendering Engine** – Server‑side rendering creates an SVG image, then layers CSS animations for water ripple and streak pulse.  
- **Hosting** – Deployed on Vercel, providing low‑latency global edge delivery.  
- **Export** – The `export as PNG` button rasterizes the SVG, allowing use on platforms that don’t support SVG or animation.

## Embedding the Card in Your README

Copy the markdown snippet generated by the tool and paste it directly into any markdown file (e.g., `README.md`):

```markdown
[![My GitHub Stats](https://github-stats.nishad.top/api/card-with-avatar?username=YOUR_USERNAME&theme=YOUR_THEME_JSON)](https://github.com/YOUR_USERNAME)
```

Replace `YOUR_USERNAME` with your GitHub handle and `YOUR_THEME_JSON` with the URL‑encoded JSON theme object you created (or use one of the preset themes). The link makes the whole card clickable, routing visitors to your profile.

---

## Exporting a Static PNG

When animation isn’t supported (e.g., LinkedIn posts, PDF documents), click **Export as PNG** on the generator. The download contains a high‑resolution image that retains all colors and layout details, ready for upload anywhere.
