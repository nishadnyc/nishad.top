# Introducing the RapidPro Flutter Plugin – My Journey from UNICEF Surveys to Open‑Source

When I was part of the development team for UNICEF’s South‑Asian survey apps back in 2021, I needed a reliable way to connect Flutter‑based mobile clients to the **RapidPro** (and its commercial counterpart **TextIt**) messaging platform. The existing native plugin was tied to my old GitHub account, so I decided to fork and refactor the codebase into a clean, stand‑alone Flutter package that anyone can drop into their project with a few lines of setup.

Below you’ll find everything you need to know about the **rapidpro** plugin (currently at version **0.0.1**)—why it exists, what it offers, how to get it up and running, and where it shines best.

---

## What Is the RapidPro Plugin?

**rapidpro** is a Flutter plugin that abstracts the complexity of communicating with a RapidPro/TextIt server through Firebase Cloud Messaging (FCM). In one place, it handles:

* **Channel registration** – obtain a unique UUID for a device/volunteer.
* **Flow initiation** – trigger any pre‑configured flow on the RapidPro server.
* **Two‑way messaging** – send arbitrary text messages to the server and receive inbound messages via FCM callbacks.

By encapsulating all the HTTP endpoints and token handling, the plugin lets developers focus on the user experience rather than the plumbing.

---

## Why I Built It

RapidPro has been a staple for NGOs, health ministries, and humanitarian agencies long before AI‑driven chatbots appeared. It provides a flow‑based, low‑code way to automate SMS, WhatsApp, and other messaging channels. However, integrating it into a modern Flutter app required:

1. **Firebase setup** on iOS and Android (the de‑facto transport for push notifications).
2. **Manual construction** of HTTP requests for registration, flow start, and message sending.
3. **Reliable handling** of asynchronous callbacks from FCM.

I wanted a plug‑and‑play solution that respected Flutter’s declarative style, so I wrapped all these steps in a single `RapidPro` class. The result is a tiny, dependency‑light package that can be injected into any state‑management solution (Provider, Bloc, Riverpod, etc.) and reused across screens.

---

## Key Features at a Glance

| Feature | What It Does | Why It Matters |
|---------|--------------|----------------|
| **Simple initialization** | Pass server URL, channel UUID, FCM token, workspace token, and URN in one constructor. | No need to chase multiple config files. |
| **Device registration** | `register()` contacts RapidPro and returns a unique device UUID. | Enables tracking of individual field workers. |
| **Flow control** | `startFlow(flow: "<flow‑uuid>")` launches any existing RapidPro flow. | Powers dynamic surveys, eligibility checks, or onboarding steps. |
| **Bidirectional messaging** | `sendMessage(message: "Hello")` posts a message to the server; inbound messages are captured via `firebaseMessaging.configure(onMessage: …)`. | Real‑time chat‑like interaction without building a custom backend. |
| **Error handling callbacks** | Each method accepts `onSuccess` and `onError` closures. | Gives you full control over UI feedback and retry logic. |
| **Platform‑agnostic** | Works on both iOS and Android once Firebase is configured. | One codebase for all mobile devices. |
| **Lightweight** | No heavy dependencies beyond `firebase_messaging`. | Keeps the app size minimal. |

## Getting Started – Step‑by‑Step

### 1. Add Firebase to Your Project  

Before the plugin can do anything, you must integrate Firebase Cloud Messaging:

* **iOS** – Follow the official guide: <https://firebase.google.com/docs/ios/setup>  
* **Android** – Follow the official guide: <https://firebase.google.com/docs/android/setup>

> The plugin relies on the FCM token you obtain from this setup.

### 2. Install the Plugin  

```bash
flutter pub add rapidpro
```

### 3. Configure FCM Callbacks  

```dart
import 'package:firebase_messaging/firebase_messaging.dart';

FirebaseMessaging firebaseMessaging = FirebaseMessaging.instance;

firebaseMessaging.configure(
  onMessage: (RemoteMessage msg) async {
    // Handle incoming RapidPro messages here
    print("New message: ${msg.notification?.title}");
  },
);
```

### 4. Instantiate `RapidPro`

```dart
import 'package:rapidpro/rapidpro.dart';

RapidPro rapidPro = RapidPro(
  server: "textit.in",                      // or "rapidpro.io"
  channel: "3gcr67-ascas32-41ac",             // Your channel UUID from RapidPro
  urn: "yourname@example.com",               // The URN that identifies the user
  fcmToken: "YOUR_FCM_TOKEN",                // Received from Firebase
  workspaceToken: "2df472f3942b4v2424284",   // Workspace token from RapidPro
  name: "John Doe",                         // Optional friendly name
);
```

> I usually store this instance in a Provider or Bloc so every screen can access it without re‑instantiating.

### 5. Register the Device  

```dart
rapidPro.register(
  onSuccess: (String uuid) {
    print("Registered with UUID: $uuid");
  },
  onError: (error) {
    print("Registration failed: $error");
  },
);
```

### 6. Start a Flow  

```dart
rapidPro.startFlow(
  flow: "c2v-23c44-2v3424",    // Replace with your actual flow UUID
  onSuccess: (response) {
    print("Flow started: $response");
  },
  onError: (e) {
    print("Failed to start flow: $e");
  },
);
```

### 7. Send a Message  

```dart
rapidPro.sendMessage(
  message: "Hello, RapidPro!",
  onSuccess: (response) {
    print("Message sent: $response");
  },
  onError: (error) {
    print("Message error: $error");
  },
);
```

That’s it—your Flutter app can now interact with any RapidPro workflow as if it were a native component.

## Real‑World Use Cases

### 1. Field‑Data Collection for NGOs  

Volunteer workers equipped with a tablet can open a survey app, trigger a RapidPro flow that asks a series of questions, and instantly push the answers to a central database. The UUID registration lets program managers track who submitted what, when, and where.

### 2. Emergency Response Coordination  

During a disaster, responders can receive broadcast alerts (via the `onMessage` callback) and reply with status updates. RapidPro’s branching logic can route messages based on location or resource availability.

### 3. Health Campaigns & Vaccination Drives  

Health workers can launch consent flows, capture phone numbers, and send reminders—all without writing a custom backend. The plugin’s lightweight nature means it can run on low‑spec Android devices common in remote areas.

### 4. Education & Literacy Programs  

Teachers can distribute lesson prompts, quizzes, and feedback forms through RapidPro flows. Since the messaging is handled over SMS/WhatsApp, families without smartphones can still participate.

## Extending the Plugin

The core API is deliberately minimal. If you need additional endpoints (e.g., fetching flow results, managing contacts, or integrating with other channels like Viber), you can:

1. Fork the repository.
2. Add new methods that call RapidPro’s REST API.
3. Expose them with the same `onSuccess` / `onError` pattern.

All contributions are welcome—feel free to open a PR or drop me a message if you hit any roadblocks.
