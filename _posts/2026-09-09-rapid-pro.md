# Streamlining Automated Messaging in Flutter with RapidPro

Automating communication at scale requires a robust system that can handle complex conversation flows without requiring constant manual intervention. During my time contributing to a [UNICEF](https://www.unicef.org/) application, I recognized the need for a seamless way to integrate flow-based messaging into Flutter mobile apps. To solve this, I developed the `rapidpro` plugin.

This plugin is a port of the RapidPro native plugin, specifically designed to implement the [RapidPro](https://rapidpro.io) or [TextIt](https://textit.in) Firebase channels within a Flutter environment.

## What is RapidPro?

RapidPro is a classic flow-based messaging system. Long before the current era of generative AI, RapidPro provided a way to automate chats through structured flows. It allows organizations to create automated conversation trees that can collect data, provide information, and interact with users in a consistent, programmable manner.

## Real-World Impact and Use Cases

The practical utility of this plugin was demonstrated through its widespread use by [Unicef.org](https://www.unicef.org/) in their survey applications across South Asia. 

In these deployments, the plugin served as a critical bridge for field workers and volunteers. It enabled them to efficiently collect and submit vital data regarding underprivileged children and women in the field, ensuring that critical information reached the right channels via an automated, reliable messaging pipeline.

Common use cases include:
* **Field Data Collection:** Automating surveys and intake forms for NGOs.
* **Automated Support:** Providing users with guided, flow-based answers to common questions.
* **Health and Education Alerts:** Sending structured information to volunteers or citizens in remote areas.

## Key Features

The `rapidpro` plugin simplifies the connection between a Flutter frontend and a RapidPro/TextIt backend via Firebase Cloud Messaging (FCM).

* **Easy Registration:** Quickly register devices to the messaging service to receive a unique UUID.
* **Flow Initiation:** Trigger specific automated conversation flows using a Flow UUID.
* **Direct Messaging:** Send outbound messages to the server with minimal code.
* **FCM Integration:** Leverages Firebase Cloud Messaging for reliable delivery and incoming message handling.

## Technical Implementation

To get started, you first need to add Firebase to your project following the standard [iOS](https://firebase.google.com/docs/ios/setup) or [Android](https://firebase.google.com/docs/android/setup) setup guides.

### Configuration
The core of the integration is the `RapidPro` class. I designed it to accept all necessary credentials—including the server URL, channel ID, workspace token, and FCM token—during initialization.

```dart
import 'package:rapidpro/rapidpro.dart';

RapidPro rapidPro = RapidPro(
	server: "textit.in",
	channel: "your-channel-id", 
	urn: "yourname@example.com", 
	fcmToken: "your-fcm-token", 
	workspaceToken: "your-workspace-token",
	name: "John Doe", 
);
```

### Handling Incoming Messages
Incoming communication is managed through the `onMessage` event via Firebase Messaging:

```dart
firebaseMessaging.configure(
	onMessage: (msg) async {
		// Handle incoming RapidPro message here
	}
);
```

### Executing Actions
Once the instance is created (which I recommend holding in a state management solution like Provider or Bloc), you can trigger the primary functions:

**1. Registering the User:**
```dart
rapidPro.register(
	onSuccess: (String uuid) {
		// Handle successful registration
	},
	onError: (e) {
		// Handle error
	}
);
```

**2. Starting a Specific Flow:**
```dart
rapidPro.startFlow(
	flow: "flow-uuid-here",
	onSuccess: (response) {
		// Flow started successfully
	},
	onError: (e) {
		// Handle error
	}
);
```

**3. Sending a Message:**
```dart
rapidPro.sendMessage(
	message: "Hello",
	onSuccess: (response) {
		// Message sent
	},
	onError: (error) {
		// Handle error
	}
);
```
