# RapidPro Flutter Plugin – Bringing Flow‑Based Messaging to Mobile Apps  

![RapidPro Logo](https://raw.githubusercontent.com/rapidpro/rapidpro/master/hs_images/rapidpro_logo.png)  
![UNICEF Logo](https://www.unicef.org/sites/default/files/styles/hero_image/public/2021-07/UNICEF_Logo.png)  

## What Is It?

A lightweight **Flutter plugin** that connects your mobile application to the **RapidPro / TextIt** platform via Firebase Cloud Messaging (FCM). It abstracts the low‑level REST calls and token handling, enabling developers to register devices, kick off flows, and exchange messages with a few lines of Dart code.  

Originally built for UNICEF’s South‑Asian survey apps, the plugin has proven effective for any field‑worker or volunteer‑driven data collection effort that relies on rapid, automated chat flows.

## Purpose  

- **Bridge Flutter apps and RapidPro’s flow‑based messaging engine** without writing custom networking code.  
- **Leverage Firebase** for reliable, push‑based delivery of incoming messages to Android and iOS devices.  
- **Simplify onboarding** for non‑technical field staff: a single QR‑scan or token registration can activate a pre‑designed conversation flow.  

## Key Features  

| Feature | Description |
|---------|-------------|
| **Zero‑configuration Firebase integration** | Works with the standard iOS and Android Firebase setup guides. |
| **One‑line RapidPro instance creation** | Provide server, channel ID, URN, FCM token, workspace token, and optional user name. |
| **Device registration** | `register()` returns a unique UUID that identifies the participant in RapidPro. |
| **Flow execution** | `startFlow(flow: "<flow‑uuid>")` launches any pre‑built RapidPro flow instantly. |
| **Two‑way messaging** | `sendMessage(message: "…")` pushes outbound messages; incoming messages are received via the `onMessage` callback in Firebase Messaging. |
| **Callback‑driven API** | Success and error handling through simple Dart callbacks—no Future/Stream boilerplate required. |
| **State‑management friendly** | Instance can be stored in Provider, Bloc, Riverpod, or any other Flutter state solution for global access. |
| **Open for contributions** | Minimal codebase and clear extension points invite community improvements. |

### Minimal Code Sample  

```dart
import 'package:rapidpro/rapidpro.dart';

final rapidPro = RapidPro(
  server: "textit.in",
  channel: "3gcr67-ascas32-41ac",
  urn: "john.doe@example.com",
  fcmToken: "YOUR_FCM_TOKEN",
  workspaceToken: "YOUR_WORKSPACE_TOKEN",
  name: "John Doe", // optional
);

// Register the device
rapidPro.register(
  onSuccess: (uuid) => print("Registered with UUID: $uuid"),
  onError: (e) => print("Registration failed: $e"),
);

// Start a flow
rapidPro.startFlow(
  flow: "c2v-23c44-2v3424",
  onSuccess: (resp) => print("Flow started: $resp"),
  onError: (e) => print("Flow error: $e"),
);

// Send a plain text message
rapidPro.sendMessage(
  message: "Hello, RapidPro!",
  onSuccess: (resp) => print("Message sent: $resp"),
  onError: (e) => print("Send error: $e"),
);
```

## Getting Started  

1. **Add Firebase to your project**  
   - iOS: Follow the official guide – <https://firebase.google.com/docs/ios/setup>  
   - Android: Follow the official guide – <https://firebase.google.com/docs/android/setup>

2. **Configure incoming message handling**  

```dart
firebaseMessaging.configure(
  onMessage: (msg) async {
    // Process inbound RapidPro messages here
  },
);
```

3. **Add the plugin to `pubspec.yaml`**  

```yaml
dependencies:
  rapidpro: ^0.0.1
```

4. **Create a `RapidPro` instance** (see code sample above).  

5. **Persist the instance** using your favorite state‑management library, then call `register()`, `startFlow()`, or `sendMessage()` as needed.

## Extending the Plugin  

The codebase is intentionally small, making it easy to:

- Add **Future‑based** methods for async/await style usage.  
- Support **media messages** (images, audio) by extending the `sendMessage` payload format.  
- Integrate **analytics** (e.g., Firebase Analytics) to track flow completion rates.  
- Provide **type‑safe models** for RapidPro’s response objects.
