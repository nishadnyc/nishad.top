# rapidpro – A Flutter Plugin for Seamless RapidPro & TextIt Integration  

## Overview  

The **rapidpro** plugin brings the power of RapidPro (and its commercial counterpart, TextIt) straight into Flutter mobile applications. By abstracting the complexities of Firebase Cloud Messaging (FCM) and RapidPro’s HTTP API, developers can register devices, launch interactive flows, and exchange messages with a few lines of Dart code.  

Built originally for UNICEF’s field‑data collection apps across South Asia, the plugin has proven its robustness in real‑world, high‑volume survey environments where volunteers and field workers need reliable, low‑latency communication with a central messaging server.

---

## Why RapidPro Integration Matters  

* **Automation at scale** – RapidPro’s flow‑based engine automates conversational logic, branching, and data capture without bespoke backend services.  
* **Cross‑platform reach** – With Flutter, a single code base powers iOS and Android, while the plugin handles the platform‑specific Firebase setup behind the scenes.  
* **Rapid deployment** – NGOs and humanitarian projects can rollout surveys, health check‑ins, or emergency alerts in weeks rather than months.  
* **Open, extensible architecture** – The plugin is deliberately lightweight, allowing developers to plug it into any state‑management solution (Provider, Bloc, Riverpod, etc.).  

---

## Core Features  

| Feature | Description |
|---------|-------------|
| **FCM‑backed inbound handling** | Simple `onMessage` hook for real‑time incoming messages. |
| **Device registration** | One‑call `register()` that returns a unique UUID for the channel. |
| **Flow execution** | Start any RapidPro/TextIt flow by UUID with `startFlow()`. |
| **Message sending** | Direct outbound messages via `sendMessage()`. |
| **Configurable parameters** | Server, channel ID, URN, FCM token, workspace token, and optional user name. |
| **Platform‑agnostic** | Works on both iOS and Android after standard Firebase setup. |
| **Extensible** | No hard dependencies on a particular state‑management library; store the `RapidPro` instance wherever you like. |

## Getting Started  

### 1️⃣ Add Firebase to Your Flutter Project  

* **iOS** – Follow the official guide: <https://firebase.google.com/docs/ios/setup>  
* **Android** – Follow the official guide: <https://firebase.google.com/docs/android/setup>  

> The plugin relies on Firebase Cloud Messaging for inbound messages, so a correctly configured Firebase project is mandatory.

### 2️⃣ Install the Plugin  

```yaml
dependencies:
  rapidpro: ^0.0.1
```

Run `flutter pub get` to fetch the package.

### 3️⃣ Configure Inbound Messaging  

```dart
import 'package:firebase_messaging/firebase_messaging.dart';

FirebaseMessaging firebaseMessaging = FirebaseMessaging.instance;

firebaseMessaging.configure(
  onMessage: (RemoteMessage msg) async {
    // Your custom handling logic here
  },
);
```

### 4️⃣ Create a RapidPro Instance  

```dart
import 'package:rapidpro/rapidpro.dart';

RapidPro rapidPro = RapidPro(
  server: "textit.in",                     // Or "rapidpro.io"
  channel: "3gcr67-ascas32-41ac",           // Channel registration URL
  urn: "yourname@example.com",             // Your user identifier
  fcmToken: "932v983bv298374vb237894v4982828uv2828", // Obtained from Firebase
  workspaceToken: "2df472f3942b4v2424284", // Workspace authentication token
  name: "John Doe",                        // Optional display name
);
```

> Keep this instance in a provider, Bloc, or any other state‑management tool for easy access throughout the app.

### 5️⃣ Register the Device  

```dart
rapidPro.register(
  onSuccess: (String uuid) {
    // Store the UUID for later reference
    print("Registered with UUID: $uuid");
  },
  onError: (error) {
    // Implement error handling strategy
    print("Registration failed: $error");
  },
);
```

### 6️⃣ Start a Flow  

```dart
rapidPro.startFlow(
  flow: "c2v-23c44-2v3424", // Replace with your flow's UUID
  onSuccess: (response) {
    print("Flow started: $response");
  },
  onError: (error) {
    print("Failed to start flow: $error");
  },
);
```

### 7️⃣ Send a Message  

```dart
rapidPro.sendMessage(
  message: "Hello, world!",
  onSuccess: (response) {
    print("Message sent: $response");
  },
  onError: (error) {
    print("Message sending error: $error");
  },
);
```

## Real‑World Use Cases  

### 1️⃣ UNICEF Field Surveys  

Volunteer teams use the plugin to push a survey flow to a mobile device. The flow collects demographic data, health status, and education metrics for children and women in underserved regions. Results are aggregated instantly in the RapidPro dashboard for rapid analysis and policy making.

### 2️⃣ Emergency Alerts  

During natural disasters, NGOs can broadcast a pre‑configured alert flow to thousands of volunteers. The flow can request status updates, location confirmations, or resource needs, all without building a custom backend.

### 3️⃣ Health Campaigns  

Public‑health initiatives can trigger reminder flows (e.g., vaccination appointments) and capture patient responses via simple SMS or app‑based chats, feeding directly into a central data repository.

### 4️⃣ Customer Support Bots  

Enterprises can embed the plugin in their consumer‑facing apps to hand off chatbot conversations to human agents when needed, using RapidPro’s routing capabilities.
