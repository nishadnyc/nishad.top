# RapidPro Flutter Plugin – Seamless Integration of Flow‑Based Messaging into Mobile Apps  

## Overview  

The RapidPro Flutter plugin brings the power of **RapidPro** and **TextIt**—two mature, flow‑based messaging platforms—directly into Flutter mobile applications. Designed with field data collection in mind, the plugin enables developers to create, register, and interact with RapidPro channels through Firebase Cloud Messaging (FCM) with just a few lines of Dart code.  

> *Originally built for UNICEF’s South Asian survey apps, the plugin has powered real‑world deployments that gather critical information on under‑privileged children and women.*  

---

## Why Use This Plugin?  

| Challenge | Solution Provided by the Plugin |
|-----------|-----------------------------------|
| **Complex Firebase & RapidPro setup** | Abstracts the boilerplate required to connect a Flutter app to a RapidPro/​TextIt channel via FCM. |
| **Hard‑coded HTTP calls** | Offers high‑level methods (`register`, `startFlow`, `sendMessage`) that handle API calls, authentication, and error handling internally. |
| **State management of the RapidPro client** | Returns a plain `RapidPro` object that can be stored in any state‑management solution (Provider, Bloc, Riverpod, etc.). |
| **Cross‑platform consistency** | Works on both Android and iOS once Firebase is configured on each platform (follow official Firebase setup links). |
| **RapidPro flow control** | Enables on‑the‑fly execution of predefined RapidPro flows, letting non‑technical field workers drive complex survey logic. |

## Getting Started  

### 1. Add Firebase to Your Project  

Before using the plugin you must have Firebase configured for your Flutter app:  

- **iOS** – [Add Firebase to your iOS project](https://firebase.google.com/docs/ios/setup)  
- **Android** – [Add Firebase to your Android project](https://firebase.google.com/docs/android/setup)  

### 2. Install the Plugin  

Add the dependency to `pubspec.yaml` (the latest version is **0.0.1**):  

```yaml
dependencies:
  rapidpro: ^0.0.1
```

Run `flutter pub get` to fetch the package.

### 3. Configure Firebase Messaging  

Set up the FCM `onMessage` handler to intercept incoming messages:  

```dart
firebaseMessaging.configure(
  onMessage: (msg) async {
    // Process inbound RapidPro messages here
  },
);
```

### 4. Create a RapidPro Instance  

Import the library and instantiate `RapidPro` with the required credentials:  

```dart
import 'package:rapidpro/rapidpro.dart';

RapidPro rapidPro = RapidPro(
  server: "textit.in",
  channel: "3gcr67-ascas32-41ac",          // Channel registration ID
  urn: "yourname@example.com",            // Your RapidPro URN
  fcmToken: "932v983bv298374vb237894v4982828uv2828",
  workspaceToken: "2df472f3942b4v2424284",
  name: "John Doe",                       // Optional human‑readable name
);
```

> **Tip:** Store the `RapidPro` instance using Provider, Bloc, Riverpod, or any other state‑management solution for easy access throughout your app.

### 5. Register the Device  

```dart
rapidPro.register(
  onSuccess: (String uuid) {
    // Device successfully registered – keep the UUID for later calls
  },
  onError: (e) {
    // Handle registration errors (network, invalid token, etc.)
  },
);
```

### 6. Start a Flow  

Supply the flow’s UUID (available in your RapidPro workspace) to trigger a survey or automation:  

```dart
rapidPro.startFlow(
  flow: "c2v-23c44-2v3424",
  onSuccess: (response) {
    // Flow started; response may contain next steps or messages
  },
  onError: (e) {
    // Flow start failed – debug or retry
  },
);
```

### 7. Send a Message  

```dart
rapidPro.sendMessage(
  message: "Hello",
  onSuccess: (response) {
    // Message delivered; response may include server acknowledgment
  },
  onError: (error) {
    // Message failed – consider retry logic
  },
);
```

## Key Features  

- **One‑Line Integration** – Minimal setup after Firebase is in place.  
- **Full RapidPro API Coverage** – Register devices, launch flows, and send outbound messages.  
- **Callback‑Based Design** – Success and error callbacks keep UI logic clean and responsive.  
- **Platform‑Agnostic** – Works on both Android and iOS without additional native code.  
- **Extensible** – Open source, encouraging community contributions and custom extensions.

## Real‑World Use Cases  

1. **Field Survey Apps** – Volunteers equipped with tablets can launch pre‑designed RapidPro flows to capture health, education, or welfare data in remote locations.  

2. **Volunteer Coordination** – Organizations can push real‑time instructions or alerts to volunteers via the same channel used for data collection.  

3. **Customer Support Chatbots** – Embed a RapidPro chatbot in a mobile app to provide automated assistance before handing over to a live agent.  

4. **Event Check‑In Systems** – Use a RapidPro flow to confirm attendance, collect feedback, and trigger follow‑up messages.  

5. **IoT Device Control** – Leverage RapidPro’s messaging backbone to send commands to devices that are also subscribed to the same FCM channel.
