# Introducing Minima: The Foundation of Jekyll Websites

If you have ever run the command `jekyll new`, you have already encountered **Minima**. As Jekyll's default and first theme, Minima is designed to provide a seamless, "zero-configuration" experience for developers and writers looking to get a website online quickly.

Minima is more than just a starter template; it is a flexible, scaffolded framework that balances simplicity with deep customizability, making it ideal for everything from personal blogs to professional portfolios.

---

## The Purpose of Minima
The primary goal of Minima is to eliminate the friction of starting a new project. By providing a pre-configured set of layouts, styles, and includes, it allows users to focus on their content rather than the underlying HTML and CSS. Whether you are building a simple landing page or a complex documentation site, Minima provides the essential structural "skeleton" required to launch a modern website.

## Key Features

### 1. Flexible Layout System
Minima utilizes a hierarchical layout system that makes site management intuitive:
*   **Base Layout (`base.html`):** The foundation of the site. All other layouts inject their content here, ensuring a consistent look across all pages.
*   **Home Layout (`home.html`):** A dynamic landing page that automatically lists posts. It allows for custom content injection *before* the posts list, giving you the freedom to create a dedicated introduction or welcome section.
*   **Page and Post Layouts:** Dedicated templates for static documents and dated blog posts.

### 2. Advanced Visual Customization (Skins)
With the release of version 3.0, Minima introduced **Skins**, allowing users to change the entire color palette of their site via a simple configuration change.
*   **Available Skins:** Users can choose from `classic` (light), `dark`, `solarized`, or `solarized-light/dark`.
*   **Adaptive Skins:** The `auto` and `solarized` skins are "adaptive," meaning they automatically switch between light and dark modes based on the visitor's operating system or browser settings using CSS media queries.

### 3. Built-in SEO and Analytics
Minima is designed for growth and visibility. It comes pre-installed with the `jekyll-seo-tag` plugin to ensure optimal meta tags for search engines. Additionally, it offers native support for **Google Analytics** and **Disqus comments**, both of which can be toggled to appear only in production environments.

### 4. Modular Customization
Minima follows a "hook" philosophy. Instead of forcing users to rewrite entire files, it provides specific placeholders:
*   **`custom-head.html`**: Add favicons or extra metadata without touching the main head layout.
*   **`custom-variables.scss`** and **`custom-styles.scss`**: Override specific CSS variables or styles while keeping the rest of the theme in sync with upstream updates.

## Common Use Cases

### Personal Blogs
Because Minima is optimized for post-listing and excerpts, it is the perfect choice for bloggers. With easy configuration for date formats and social media links in the footer, a professional blog can be launched in minutes.

### Professional Portfolios
Using the `nav_pages` configuration, users can easily curate a navigation menu featuring "About," "Portfolio," and "Contact" pages. The clean, minimalist aesthetic ensures that the user's work remains the center of attention.

### Project Documentation
The simple page-based layout makes Minima an excellent choice for small project documentation or "ReadMe" style websites where clarity and readability are paramount.

## Getting Started quickly
To start using Minima, simply add the gem to your `Gemfile`:

```ruby
gem "minima"
```

Then, update your `_config.yml` to activate the theme:

```yaml
theme: minima
```

### Pro Tip: Stability in Development
As Minima is under active development toward major releases, the project maintainers recommend pointing to a **specific git ref** (commit hash) rather than the `master` branch. This prevents "breaking changes" from unexpectedly altering your site's render during an update.

*Example for `_config.yml`:*
`remote_theme: "jekyll/minima@1e8a445"`
