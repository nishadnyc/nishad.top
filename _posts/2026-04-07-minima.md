# Introducing Minima: The Default Theme for Jekyll

Minima is the official default theme for Jekyll. Designed to be lightweight and versatile, it is the foundational theme provided to users whenever they execute the `jekyll new` command. Its primary goal is to provide a "zero-configuration" experience, allowing developers to get a professional-looking site up and running immediately without needing to spend hours on initial styling.

## Purpose and Design Philosophy

Minima serves as a scaffold for a wide variety of websites, from personal blogs to professional portfolios. It is built to be unobtrusive, offering a clean aesthetic that stays out of the way of the content. 

The theme is engineered for extensibility. While it works perfectly out of the box, it is designed so that users can easily override specific layouts, includes, or styles to transform the site into a unique brand experience without losing the benefit of upstream updates.

## Key Features

### Flexible Layout System
Minima utilizes a hierarchical layout structure to maintain consistency across different page types:
*   **Base Layout (`base.html`):** The structural foundation for the entire site.
*   **Home Layout (`home.html`):** A dynamic landing page that can display custom content from an `index` file followed by an automated listing of recent posts.
*   **Page and Post Layouts:** Specialized templates for standard documents and chronological blog entries.

### Advanced Styling and Skins
Starting with version 3.0, Minima introduced a robust skinning system, allowing users to change the entire color palette via a simple configuration change.
*   **Available Skins:** Includes `classic` (light), `dark`, and `solarized` variants.
*   **Adaptive Themes:** The `auto` and `solarized` skins utilize CSS Media Queries (`prefers-color-scheme`) to automatically switch between light and dark modes based on the visitor's operating system or browser settings.
*   **Sass Integration:** The theme uses Sass for styling, providing hooks like `custom-variables.scss` and `custom-styles.scss` for users to apply their own branding.

### Integrated Tooling and Components
Minima comes pre-packed with essential web features:
*   **SEO Optimization:** The `jekyll-seo-tag` plugin is pre-installed to ensure optimal meta tags for search engines.
*   **Social Integration:** A dedicated social links system using Font Awesome icons allows users to easily link to platforms like GitHub and X (Twitter) via the `_config.yml` file.
*   **Production-Ready Modules:** Built-in support for Google Analytics and Disqus comments, both of which are configured to activate only in production environments.

## Potential Use Cases

Because of its minimalist approach and high flexibility, Minima is ideal for several types of projects:

*   **Personal Blogs:** With automated post listings, excerpt support, and built-in comment integration, it is a turnkey solution for writers.
*   **Developer Portfolios:** The clean design and easy navigation customization make it a great choice for showcasing projects and professional experience.
*   **Documentation Sites:** The simple page layouts and consistent structure provide a clear reading experience for technical guides.
*   **Project Landing Pages:** The flexible home layout allows developers to create a high-impact introduction followed by a feed of project updates.

## Installation and Setup

To integrate Minima into a Jekyll project, add the following to the `Gemfile`:

```ruby
gem "minima"
```

After running `bundle`, the theme is activated by adding a single line to the `_config.yml` file:

```yaml
theme: minima
```
